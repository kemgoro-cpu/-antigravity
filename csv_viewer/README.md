# CSV Chart Viewer

CSV / TRN ファイルをブラウザだけで読み込み、複数チャンネルの時系列データをインタラクティブに可視化する Web アプリです。依存ライブラリは `lib/` に同梱しているため、インターネット接続なしで動作します。

## 起動方法

`index.html` をブラウザで開きます。ローカルサーバーは不要です。

```text
csv_viewer/
├─ index.html
├─ app.js
├─ parser-utils.js
├─ styles.css
└─ lib/
```

## CSV / TRN の読み込み

サイドバーの Files エリアへ `.csv` または `.trn` ファイルをドラッグ&ドロップするか、Browse Files から選択します。最初に読み込んだファイルが Main、追加ファイルが Sub として扱われます。

想定 CSV 形式:

```csv
Time,RPM,Torque,Speed
s,rpm,Nm,km/h
0.000,1500,45.2,0.0
0.001,1502,45.3,0.1
```

- 1 行目: チャンネル名
- 2 行目: 単位
- 3 行目以降: 数値データ
- `Time` または `時間` を含む列を時間軸として検出します
- 時間単位が `ms` / `msec` / `sec` / `s` の場合は秒へ自動変換します
- 複数ファイル読み込み時、Time 単位が未記載でも時間幅が 1000 倍程度違う場合は `ms` / `sec` を自動推定します
- 自動判定が違う場合は、Files一覧の `Time` セレクトでファイルごとに `s` / `ms` を手動指定できます

ヘッダー行が異なるファイルでは、Settings の Name Row / Unit Row を変更してから読み込んでください。

## 文字コード

Settings の Encoding で読み込み文字コードを指定できます。

- `Auto`: UTF-8 / Shift_JIS / UTF-16 の BOM や先頭バイト列から自動判定
- `UTF-8`: UTF-8 固定
- `Shift_JIS`: Excel や計測器由来の CP932 / Shift_JIS CSV 向け
- `UTF-16LE` / `UTF-16BE`: UTF-16 CSV 向け

読み込み後はサイドバーの Parse Preview とファイル一覧バッジに判定された文字コードが表示されます。日本語のチャンネル名や単位が文字化けする場合は、Encoding を `Shift_JIS` に固定して再読み込みしてください。

## 読み込み状態とエラー

読み込み中は Files セクションに処理中のファイル名、フェーズ、処理行数が表示されます。時間データや選択チャンネルの読み込みは、右側の X ボタンでキャンセルできます。

ヘッダー行、Time 列、データ開始行、数値データに問題がある場合は、原因と確認ポイントをトースト通知で表示します。

## 主な機能

- チャンネル一覧から表示 / 非表示を切り替え
- チャンネル名検索
- チャンネルごとの Y 軸 min / max 指定
- 複数ファイルの重ね合わせ表示
- Sub ファイルの Time Shift 手動調整
- 複数ファイル間の Time 単位自動調整
- ファイルごとの Time 単位手動補正と設定保存
- Auto Align による時系列位置合わせ
- Y 軸ラベルのドラッグで3本以上のチャンネルを同一チャートへ重ね合わせ
- 同じ単位は同じY軸へ自動配置し、異なる単位は共有軸または新規軸を選択
- Arrange モードで描画中のチャート順を上下に並べ替え
- Bit チャンネルの自動検出と表示切り替え
- Custom RAM による計算チャンネル追加
- LTTB サンプリングによる大容量データの高速描画
- PNG 保存、クリップボードコピー
- 設定の JSON エクスポート / インポート
- Settings セクションで設定プリセットを保存 / 適用 / 削除
- Channel Map で、名前が違うSub側チャンネルをMainチャンネルへ対応付け

## Custom RAM

既存チャンネルの四則演算や関数で、新しいチャンネルを追加できます。作成時に任意の単位を指定でき、作成後も一覧の編集アイコンから変更できます。

例:

```text
RPM / 60
Torque * RPM * 3.14159 / 30
sqrt(pow(X, 2) + pow(Y, 2))
```

Sub ファイルのチャンネルは `s1:チャンネル名` の形式で参照できます。

## チャート配置と複数Y軸

- ツールバーの Arrange を有効にすると、チャート枠を上下ドラッグして表示順を変更できます。
- 通常モードで単独チャートのY軸ラベルを別チャートへドラッグすると、同じ枠へ重ねられます。
- 同じ単位のY軸があれば自動共有します。異なる単位や単位なしの場合は、既存軸の共有または新しいY軸を選択します。
- 重ね合わせたチャートのY軸ラベルをダブルクリックすると、軸割り当ての変更やチャンネルの分離ができます。

## デバッグ

ファイル一覧の虫眼鏡アイコンから Parse Info を開くと、検出された文字コード、ヘッダー行、Time 列、Time 単位の判定結果、列一覧、読み込みプレビューを確認できます。

## 設定プリセット

Settings セクション下部のプリセット操作で、現在のヘッダー行、文字コード、サンプリング、Custom RAM、選択チャンネル、Y 軸範囲などをブラウザに保存できます。同じ形式のログを繰り返し見るときに使います。

- 保存: ディスクアイコン
- 適用: 再生アイコン
- 削除: ゴミ箱アイコン

## Channel Map

Main と Sub で同じ物理値なのにチャンネル名が違う場合、Channels 一覧のリンクアイコンから別名を登録できます。

例: Main の `車速` に対して Sub 側の `Vehicle Speed` を登録すると、`車速` を選択したときに Sub の `Vehicle Speed` も同じグリッドへ重ね描画されます。候補は単位一致や名前の近さで並びますが、自動では適用されません。

登録した対応表は通常設定、設定JSON、プリセットに保存されます。

## 開発メモ

ブラウザ不要のユーティリティテストは次のコマンドで実行できます。

```bash
rtk node tests/parser-utils.test.js
```

構文チェック:

```bash
rtk node --check app.js
rtk node --check parser-utils.js
```
