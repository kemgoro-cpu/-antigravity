# CSV Chart Viewer

CSV / TRN ファイルをブラウザだけで読み込み、複数チャンネルの時系列データをインタラクティブに可視化する Web アプリです。依存ライブラリは `lib/` に同梱しているため、インターネット接続なしで動作します。

## 起動方法

`index.html` をブラウザで開きます。ローカルサーバーは不要です。

## 読み込みから確認まで（2026-10-30）

1. **適用前に確認する**: 左の「設定を確認してファイルを開く」でCSV / TRNを指定します。名前行は自動／指定、単位行は自動／なし／指定、時間列・区切り・文字コードをファイルごとに訂正できます。「この設定を全ファイルへ適用」は一括指定、「この設定を次回の既定にする」は明示的な再利用です。通常の選択・ドロップは即時読み込みで、常に確認するチェックもあります。プレビューは先頭256 KiB・最大50レコードです。
2. **解析対象をそろえる**: 波形上の「解析対象」で表示範囲／選択区間／全体を選びます。比較・統計・XY・基準CSV・メモとHTMLレポートの現在の統計が同じ区間・時間基準を使います。区間選択すると「選択区間」に切り替わり、別の場所へズームしてもその区間を保持します。「元の時刻で確認」も各解析へ反映します。Drive Indexは独立した評価条件です。
3. **元データへ戻る**: 解析対象バーの「元データ」でファイルを選び、選択したチャンネルのサンプルを100行ずつ表示します。元レコード番号、秒に換算した元時刻、時間差を反映した表示時刻を区別します。行クリックで波形に目印を表示し、通常の波形クリックで近い行へ戻れます。計算列は「計算値」と区別します。補間点・描画用の間引き点の一覧ではありません。
4. **品質を確認する**: 「品質診断」は時刻の重複・逆転・大きな間隔候補と除外時刻をファイル全体で確認し、選択チャンネルの欠損・一定値を解析対象の区間で確認します。元列の変換不能は全体の件数と区間内の保持明細を分け、先頭1,000件を超える詳細は保持しません。大きな間隔は正の時刻差の中央値の10倍超が候補です。一定値は正常状態でも生じるため「要確認」で、異常と断定しません。品質表の「欠損合計」は変換不能を含む非有限値の合計です。保持明細では空欄・文字NaNと、非空欄で数値変換結果が非有限になる変換不能値を区別します。
5. **次回の復元可否を見る**: ファイルごとに保存中／保存済み・次回復元可能／今回のみ／保存失敗／非対応と最終成功時刻を表示します。容量超過や失敗は理由を読み「再試行」。合計200 MiBを上限とするブラウザ内保存なので、元ログと必要な設定JSONは別途保管します。
6. **Drive Indexの条件を確認する**: 実測・CSV目標車速はkm/h、燃料流量はL/hが必要です。時間は読み込み時に秒へ換算しますが、推定だけの場合はs / msを明示確認します。速度・時間が未確認／不一致のファイルは未評価、燃料だけの問題なら燃費を未評価にします。条件変更後の旧結果は「未更新」として扱い、「再計算」で更新します。単位の自動換算はしません。

元データの「元レコード番号」は**空行を除く1始まりのCSVレコード番号**で、テキストエディターの物理行番号とは異なる場合があります。値は読み込み済み数値で、元セルの文字列表現を完全に保存する表ではありません。プレビュー・診断・時間合わせは元CSV / TRNを変更せず、外部へ送信しません。

## 操作性の改善（2026-09-28）

- CSV / TRNは画面全体へのドロップ、または「ファイルを選択」で開けます。読み込み後の案内からチャンネル検索へ進めます。
- 上部の「ファイル」で左パネルを開閉できます。幅760px以下では引き出し式になり、閉じるボタン・背景・Escで閉じます。検索中のEscは最初に検索語を消します。
- 幅1279px以下では比較パネルを波形に重ねて表示します。狭い幅へ変更したときは閉じ、必要なときに「比較パネル」から開けます。初期状態や1ファイルだけのときも波形の領域を優先します。
- `/` または `Ctrl+K` でチャンネル検索へ移動します。検索件数・表示中の件数を確認でき、検索文字や絞り込みをその場で解除できます。
- ツールバーは操作名を表示します。チャートの高さ調整は「表示」、ファイルの一括クリアは左パネルにあります。サイドバー境界は矢印キーでも幅を変更できます。
- ファイルを外す操作と作業の一括クリアは、削除対象とリセット範囲を確認してから実行します。元のCSV / TRNは削除しません。
- 比較パネルを切り替えたりチャンネルを追加したりしても、メモ・テンプレート名・未適用の対応候補・時間合わせの入力は作業中の下書きとして保持します。**未保存の下書きは再読み込みをまたいで保存しません。**
- 区間や比較条件を変えると古い結果とプレビューを無効にし、更新を案内します。保存中の条件変更によるメモ画像と数値の食い違い、連打による重複保存も防ぎます。

調査内容と検証範囲は [UI/UXレビュー結果](UI_UX_REVIEW.md) を参照してください。

## 比較ワークスペース（2026-09-09）

左にファイルとチャンネル、中央に波形、右に比較パネル、下に全体ナビゲーターを配置しています。
右パネルは上部の「比較パネル」で開閉できます。画面幅が狭い場合は波形の上に重なって開きます。
読み込み設定・Custom RAM・イベント検出は左の「読み込み設定・計算・イベント」から、
従来の時間シフト・並べ替え・計算差分・XY・Drive Indexは「解析ツール」から開けます。

### 最短の比較手順

1. CSV / TRNを2つ以上読み込み、左で比較するチャンネルを選択します。
2. 右の「準備」で基準ファイルと表示名を設定します。名前が違う信号は対応先を選び「対応を適用」。
   名前の近い候補は一括選択できますが、適用するまで元の対応は変わりません。
3. 「時間合わせ」でチャンネル・探索幅・評価区間を指定し「自動合わせをプレビュー」。
   基準（実線）、現在の比較（灰色破線）、候補（橙色破線）とRMSEを確認して適用します。
   「2点指定・数値で合わせる」ではプレビューの基準→現在の比較波形をクリックするか、
   基準時刻と比較の元時刻を入力できます。適用するまで実際の時間差は変わりません。
4. 「比較結果」の「比較を更新」で最大絶対差・発生時刻・平均差・RMS差・欠損数を確認します。
   許容差を入力してEnterまたは別の場所をクリックすると再計算し、超過した項目を先頭に表示します。
   「許容差超過」の表示とオレンジの帯・縦線で場所を確認し、「最初の超過へ」「前へ／次へ」で順に移動できます。
   チャンネル名を押すと最大差付近へ移動します。「チャンネル順」への並べ替えも選べます。

許容差は `|基準 − 比較|` が指定値を上回る基準サンプルを判定します。同じ値は超過に含みません。
連続する超過点の最初から最後までを帯、単発の超過点を縦線で表示します。サンプル間の境界時刻や超過時間は推定しません。
欠損・範囲外では区間を分断し、有効点なし・単位不一致・未対応・許容差未設定を正常とは判定しません。
欠損を含む許容差内の結果も「有効点は許容差内・欠損あり」と区別します。

結果からの移動中は元の比較区間を保持し、許容差を変えたときもその区間を再計算します。
手動で時間方向へズームする、選択区間・対応・時間差・計算式・時間単位を変更する場合は、古い結果と帯を解除するため「比較を更新」で計算し直してください。
Y軸だけのズームや重ね合わせ／上下比較／差分の切替では比較結果を維持します。上下比較の強調は対象の比較ファイルの段に表示します。

「重ね合わせ／上下比較／差分」は配置を保持したまま切り替えられます。
差分の符号は **基準 − 比較**、Y軸は自動範囲です。上下比較の各段にはファイル名を表示します。
「元の時刻で確認」は表示と共通解析の時間シフトを解除します（保存済みの時間差は変更しません）。
時間合わせに依存するクロスファイル計算線はこの表示中は非表示になります。

### 区間・チャンネル操作

- 「区間を選択・解析」で波形を横ドラッグすると、全段をハイライトし、拡大・区間比較・統計・イベント登録・メモ・画像コピーを選べます。
- 既存の2点カーソル計測でも同じ区間メニューを表示します。「×」で選択解除します。
- 全体ナビゲーターをドラッグして区間を指定、クリックして表示区間の中心を移動できます。開始／終了秒の直接入力も可能です。
- チャンネルを波形の中央にドロップすると重ね合わせ、上端／下端付近にドロップすると独立した段へ挿入します。異なる単位は新しいY軸を作ります。
- チャンネル検索は登録した検索別名・単位にも対応。「圧力」等の日本語別名を登録できます。
  検索欄の↓で候補へ移動、↑↓で候補選択、Enter／Spaceで表示を切り替えられます。
- 「表示中」「全ファイル共通」「未対応あり」「お気に入りセット」で絞り込めます。

### メモと比較テンプレート

「メモ・保存」で選択／表示区間のメモを保存すると、波形画像、ファイル、シフト、配置、
計算式、対応付け、比較数値も保存します。区間リンクから保存時の状態へ戻せます。
「メモ付きHTMLレポート」には保存時の画像と条件・数値を埋め込みます。
メモは20件まで、画像はPNGのData URL文字列が400,000文字未満の場合に保存（大きい画像は数値・条件のみ保存）。容量不足時は通知します。
削除はUndoで戻せます。通常のセッション復元にもメモと比較設定を含みます。

比較テンプレートには配置・選択・式・対応・許容差・検索別名・時間合わせの条件を保存します。
新しいログを読み込んでから適用してください。基準と比較ファイルの順番に対応付けを移し、
**前回の時間差は引き継がず0秒に戻す**ため、新しいログで時間合わせを再計算・確認します。
不足チャンネルは通知します。テンプレートはJSONでも共有でき、ログデータやメモ画像を含みません。
ファイル削除／Clear Allでも保存済みテンプレートは残ります。

### 数値の扱い

- 数値比較は描画用の間引きデータを使わず、元データから計算します。比較ワークスペースの差分・補間比較・自動時間合わせでは、重複・逆転・非有限時刻がある場合は理由付き未評価にします。統計は逆転でも区間内の全有効点を集計し、元の時刻配列は並べ替えません。
- アナログ信号は基準側のサンプル時刻へ線形補間、0/1のBit信号は直前値を保持して比較します。
- 範囲外は外挿せず、NaNや欠損値をまたいだ補間をしません。平均差・RMS差は有効サンプルの等重み平均です。
- Bitの不一致時間は両ファイルの切替時刻を合わせて積算します。最初の切替時刻を並べ、
  同じ遷移（例0→1）なら「比較 − 基準」の時刻差も表示します。最大絶対差とは符号の定義が異なります。
- 単位が違うチャンネルは重ね合わせ・差分・数値比較から除外し、右パネルに理由を表示します。
  自動単位換算は行いません。単位なし同士は同じ物理量か確認してください。
- 自動時間合わせは現在のシフトを中心に探索します。有効な重なりが60%未満、3点未満、
  または変化のない信号では適用候補を出しません。周期波形は目視でも確認してください。

## CSV / TRN の読み込み

サイドバーの Files エリアへ `.csv` または `.trn` ファイルをドラッグ&ドロップするか、Browse Files から選択します。最初に読み込んだファイルが Main、追加ファイルが Sub として扱われます。

想定 CSV 形式:

```csv
Time,RPM,Torque,Speed
s,rpm,Nm,km/h
0.000,1500,45.2,0.0
0.001,1502,45.3,0.1
```

- 1 行目: チャンネル名
- 2 行目: 単位、または最初の数値データ（単位行は省略可能）
- 単位行の次から: 数値データ
- `Time` または `時間` を含む列を時間軸として検出します
- 時間単位が `ms` / `msec` / `sec` / `s` の場合は秒へ自動変換します
- 複数ファイル読み込み時、Time 単位が未記載でも時間幅が 1000 倍程度違う場合は `ms` / `sec` を自動推定します
- 自動判定が違う場合は、Files一覧の `Time` セレクトでファイルごとに `s` / `ms` を手動指定できます

ヘッダー行が異なるファイルでは、「設定を確認してファイルを開く」で名前行・単位行を「指定」に切り替え、時間列も確認してから読み込みます。単位行の「なし」も指定できます。

## 文字コード

Settings の Encoding で読み込み文字コードを指定できます。

- `Auto`: UTF-8 / Shift_JIS / UTF-16 の BOM や先頭バイト列から自動判定
- `UTF-8`: UTF-8 固定
- `Shift_JIS`: Excel や計測器由来の CP932 / Shift_JIS CSV 向け
- `UTF-16LE` / `UTF-16BE`: UTF-16 CSV 向け

読み込み後はサイドバーの Parse Preview とファイル一覧バッジに判定された文字コードが表示されます。日本語のチャンネル名や単位が文字化けする場合は、Encoding を `Shift_JIS` に固定して再読み込みしてください。

## 読み込み状態とエラー

読み込み中は Files セクションに処理中のファイル名、フェーズ、処理行数が表示されます。時間データや選択チャンネルの読み込みは、右側の X ボタンでキャンセルできます。

ヘッダー行、Time 列、データ開始行、数値データに問題がある場合は、原因と確認ポイントをトースト通知で表示します。

## 主な機能

- チャンネル一覧から表示 / 非表示を切り替え
- チャンネル名検索
- チャンネルごとの Y 軸 min / max 指定
- 複数ファイルの重ね合わせ表示
- Sub ファイルの Time Shift 手動調整
- 複数ファイル間の Time 単位自動調整
- ファイルごとの Time 単位手動補正と設定保存
- Auto Align による時系列位置合わせ
- Y 軸ラベルのドラッグで3本以上のチャンネルを同一チャートへ重ね合わせ
- 同じ単位は同じY軸へ自動配置し、異なる単位は共有軸または新規軸を選択
- Arrange モードで描画中のチャート順を上下に並べ替え
- Bit チャンネルの自動検出と表示切り替え
- Custom RAM による計算チャンネル追加
- LTTB サンプリングによる大容量データの高速描画
- PNG 保存、クリップボードコピー
- 設定の JSON エクスポート / インポート
- Settings セクションで設定プリセットを保存 / 適用 / 削除
- Undo / Redo（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z、ツールバーボタン）。ズーム・チャンネル選択・マージ・Custom RAM・色変更などの操作を時系列順に戻せる。ファイル追加 / 削除 / Clear All / Time 単位変更の時点で履歴はリセットされる
- チャートの縦幅調整: ツールバーの `Fit / − / ＋` で全体を段階調整（入りきらない分は縦スクロール）。グリッドの下端境界をドラッグすると個別に高さ変更でき、境界のダブルクリックでそのチャートだけ自動に戻る
- チャートのフォントサイズ: ツールバーで 小 / 標準 / 大 / 特大 を選択（チャンネル名・軸の数値・ホバー値が連動）。長いチャンネル名はチャート高さに収まらない分が「…」で自動省略される
- Channel Map で、名前が違うSub側チャンネルをMainチャンネルへ対応付け
- ライト / ダークテーマ切替（ツールバー右の太陽 / 月アイコン。選択は保存される）
- カーソル計測（ツールバーの Measure、ショートカット M）: チャートを2回クリックすると、区間の Δt と表示チャンネルごとの A / B / Δ / min / max / mean / RMS をパネル表示。Esc で解除
- イベント検出（サイドバーの Events）: 条件式（例 `Actual_Speed > 120`）を満たす区間を検出して一覧表示+チャート上をハイライト。行クリックで該当区間へズーム
- セッション自動復元: ブラウザ内に保存成功したファイルと各取込設定を次回復元します。ファイルごとの保存状態・失敗理由・再試行・最終成功時刻を表示します（合計200 MiBまで）。ファイル削除 / Clear All の復元データ削除に失敗した場合も通知します。
- 統計サマリ: 共通の解析対象（表示範囲／選択区間／全体）の min / max / mean / σ を元データから表示
- 基準データの CSV エクスポート: 共通の解析対象区間 × 基準側の選択チャンネル（Custom RAM の計算結果を含む）をCSV保存
- XY プロット（ツールバーの XY）: 任意チャンネル同士の散布図（例: 車速 vs 燃料流量）。main / sub 重ね描き、共通の解析対象・元時刻基準との連動、入力／描画点数・除外理由の表示
- 差分カーブ生成（ツールバーの Diff、Sub があるとき）: Main と Sub の同名チャンネルから選んで Main − Sub の差分を Custom RAM として一括生成
- HTML レポート出力（ツールバーの Report）: チャート画像・ファイル情報・統計・Drive Index・Custom RAM・イベント一覧を1枚の HTML に保存
- チャンネルセットのお気に入り（Channels の ★）: よく見るチャンネルの組み合わせを保存してワンクリック適用（Clear All でも消えない）

## Custom RAM

既存チャンネルの四則演算や関数で、新しいチャンネルを追加できます。作成時に任意の単位を指定でき、作成後も一覧の編集アイコンから変更できます。

例:

```text
RPM / 60
Torque * RPM * 3.14159 / 30
sqrt(pow(X, 2) + pow(Y, 2))
SPD > 60 && GEAR == 4
```

Sub ファイルのチャンネルは `s1:チャンネル名` の形式で参照できます。
比較（`> < >= <= == !=`）と論理（`&& ||`）も使えます（結果は 1 / 0 の系列。イベント検出の条件式と同じ文法）。使える関数と演算子の一覧は Custom RAM 見出し横の「?」から確認できます。

### 走行モードの目標車速チャンネル（`@MDC` など）

Drive Index が走行モードを判別すると、そのモードの目標車速がチャンネルとして自動で追加されます（`@MDC` / `@NEDC` / `@WLTC3b_3` など、単位 km/h）。チャンネル一覧でクリックすればグラフに重ねられます。

- 実測ログの整合位置に合わせて配置されるので、実測車速とそのまま重なります。モード区間の外（計測前後の余分なデータ）には線を引きません。
- Main / Sub それぞれのファイルの時間軸に合わせて作られます。
- Custom RAM の式からも参照できます。例えば `Actual_Speed - @MDC` で追従誤差の波形が得られます。
- 判別結果から毎回作り直されるため、走行モードを切り替えると中身も名前も入れ替わります。目標車速に CSV の列を指定した場合は作られません。

### NEDC のトランスミッション（MT / AT）

NEDC は MT 車と AT 車で目標車速のパターンが違います。MT 版は加速の途中に 15 / 35 / 50 km/h で 2 秒間の定速保持（変速のための区間）が 15 箇所ありますが、AT 版はその区間も加速を続けます。アプリはこの違いを見て **MT / AT を自動判定**し、`NEDC (MT)` / `NEDC (AT)` として表示します（チャンネルは `@NEDC_MT` / `@NEDC_AT`）。

AT 車のログを MT 版の目標で評価すると、加速区間のずれで RMSSE と DR（距離偏差）が実力より悪く出ます。判定が合っているかは Drive Index モーダルの「自動判別」表示で確認でき、手動で切り替えることもできます。

WLTC と MDC は目標車速トレースが 1 本しかなく MT / AT で違いが無いため、区別しません。

## チャート配置と複数Y軸

- ツールバーの Arrange を有効にすると、チャート枠を上下ドラッグして表示順を変更できます。
- 通常モードで単独チャートのY軸ラベルを別チャートへドラッグすると、同じ枠へ重ねられます。
- 同じ単位のY軸があれば自動共有します。異なる単位や単位なしの場合は、既存軸の共有または新しいY軸を選択します。
- 重ね合わせたチャートのY軸ラベルをダブルクリックすると、軸割り当ての変更やチャンネルの分離ができます。

## デバッグ

ファイル一覧の虫眼鏡アイコンから Parse Info を開くと、検出された文字コード、ヘッダー行、Time 列、Time 単位の判定結果、列一覧、読み込みプレビューを確認できます。

## 設定プリセット

Settings セクション下部のプリセット操作で、現在のヘッダー行、文字コード、サンプリング、Custom RAM、選択チャンネル、Y 軸範囲などをブラウザに保存できます。同じ形式のログを繰り返し見るときに使います。

- 保存: ディスクアイコン
- 適用: 再生アイコン
- 削除: ゴミ箱アイコン

## Channel Map

Main と Sub で同じ物理値なのにチャンネル名が違う場合、Channels 一覧のリンクアイコンから別名を登録できます。

例: Main の `車速` に対して Sub 側の `Vehicle Speed` を登録すると、`車速` を選択したときに Sub の `Vehicle Speed` も同じグリッドへ重ね描画されます。候補は単位一致や名前の近さで並びますが、自動では適用されません。

登録した対応表は通常設定、設定JSON、プリセットに保存されます。

## 開発メモ

ブラウザ不要のユーティリティテストは
`csv_viewer/` で次のコマンドを実行すると一括で走ります（1本でも失敗すると非0終了）。

```bash
npm test
```

従来どおり `node tests/<name>.test.js` で1本ずつ実行することもできます
（parser-utils / settings-utils / history-utils / layout-utils / chart-options-utils / drive-index-utils）。

構文チェック:

```bash
node --check app.js
node --check parser-utils.js
node --check settings-utils.js
node --check history-utils.js
node --check layout-utils.js
node --check chart-options-utils.js
node --check drive-index-utils.js
node --check drive-cycles-data.js
```

同梱サンプル `NEDC_sample_A/B/C.trn` は `node scripts/generate_nedc.js` で再生成できます。
乱数はシード固定（mulberry32）のため出力は決定的で、何度実行しても同じ内容になります。
出力先は省略時 `csv_viewer/` 直下（コミット済みサンプルを上書き）で、
`node scripts/generate_nedc.js <出力ディレクトリ>` で変更できます。

設定の保存形式（`_version`）を変更するときは、`settings-utils.js` の
`SETTINGS_VERSION` とマイグレーション処理、テストを必ずセットで更新してください。

### UI文言の言語ポリシー

- **ユーザー向けメッセージ（トースト・モーダル・検証メッセージ・確認ダイアログ）は日本語が主言語。**
  新しいメッセージを追加するときは日本語で書くこと。
- **操作ラベルも日本語を基本とし、ボックスズーム・計測・保存など実際の動作が伝わる名前にする。**
  CSV / PNG / XY / Drive Indexなど形式名・機能名はそのまま使う。
- エラートーストの詳細欄に載せる技術情報（例外メッセージ・ファイル名・スタック等）は
  原文のまま表示してよい。
- メッセージカタログ（`messages.js` 等）への全文字列集約は、翻訳・多言語化の要件が
  出るまで実施しない（文字列の大半がテンプレートリテラルで状態と密結合しており、
  現時点では抽出コストとリグレッションリスクが利益を上回るため）。

チャートのテーマ色は `styles.css` の `:root` トークンが単一情報源。
EChartsはCSS変数を解釈しないため、app.js 起動時に `cssVar()`（`T` 定数の構築）で
実値へ解決している。`--bg-main` 等を変更するとチャート・PNG出力の背景も追従する。
