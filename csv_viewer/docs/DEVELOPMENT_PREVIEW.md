# 開発・検証用プレビュー

普段は `index.html` を直接開いて使えます。画面の修正やデモの確認には、PC内で動く開発用プレビューも使えます。

## 起動と停止

1. `csv_viewer` 内の **`開発プレビュー.cmd`** をダブルクリックします。
2. ブラウザで `http://127.0.0.1:8765/?preview=1` が開きます。開かなければ、起動したコンソールに表示されるURLをブラウザへ入力します。
3. 画面上部の **「デモを読み込む」** を押します。ファイル選択は不要です。
4. 終了するときは、サーバーを起動したコンソールで **Ctrl+C** を押します。ブラウザのタブを閉じるだけではサーバーは止まりません。

Node.js 18以上が必要です。起動ファイルはPATH上のNode.jsを探し、利用できなければユーザーのCodex同梱ランタイムを探します。通常利用の `index.html` にはNode.jsは必要ありません。

同じフォルダーのプレビューがすでに起動していれば、それを再利用します。停止は最初のコンソールで行います。別のアプリや別フォルダーが8765番を使っている場合は、相手を停止せずエラーを表示します。

開発者は `csv_viewer` フォルダーで次のコマンドも使えます。

```powershell
npm run dev
npm run dev:open
npm run dev -- --port 8901
```

`dev` はURLを表示、`dev:open` はブラウザも開きます。ポートを変えた場合は、表示されるURLを使ってください。

## デモで確認できること

同梱の `デモ_燃費率マップ付き走行ログ.csv` と `練習用_詳細燃費率ﾏｯﾌﾟ.csv` を読み込みます。120秒・1,201点の回転数／トルクの波形と、100 rpm×2 Nmの詳細背景を同じ画面に表示します。いずれも架空データで、実測エンジンの特性ではありません。

- 波形上でカーソルを動かすと、マップの目印が連動します。
- 波形とマップの境界をドラッグして、左右の幅を変えられます。
- 「拡大操作」をONにし、マップのグラフ内でホイール操作すると拡大します。「全体に戻す」で復帰します。
- 「大きく表示」と「並べて表示に戻る」を切り替えられます。

既存のログがある場合や読込中は、デモを重ねて読み込みません。再試行は、空のプレビュー画面で行います。デモ読込のために既存ログを自動削除することはありません。

## 通常の作業との違い

**開発プレビューの作業は自動保存しません。再読み込みすると空の画面に戻ります。** プレビュー内で保存したプリセット・お気に入り・比較テンプレートも再読込で消えます。残したい設定や結果は、既存の「保存・再利用」からJSONやレポートなどのファイルへ書き出してください。通常画面の保存済み設定・ログ・比較テンプレートには触れません。

開発用の案内は、PC内のHTTPページで `?preview=1` を付けたときだけ表示します。通常のファイル直接起動には追加ボタンを出しません。

サーバーは `127.0.0.1` のみに接続し、インターネットへ公開しません。配信対象は `csv_viewer` フォルダー内です。ブラウザで選択したログをサーバーへアップロードする機能はなく、ファイルの書込み・削除を受け付けるAPIもありません。

## Codexで画面操作を検証するとき

ブラウザ操作の許可は、ソース編集やコマンド実行の許可とは別です。このプレビューを追加しただけで、すべての画面操作やファイル選択が許可されたとは扱いません。

2026-11-01時点の今回の検証は、隔離したテスト用フォルダーでのHTTP配信と、Node上のデモ読込・既存描画の回帰テストです。変更後のアプリ実画面による自動操作は、既存のアクセス制限が解除されたことを確認できていないため未実施です。

2026-11-02には、利用者が起動した `http://127.0.0.1:8765/?preview=1` をChrome接続のComputer Useで開き、デモ読込・波形カーソル連動・マップのホイール拡大／ドラッグ移動／全体復帰・分割表示を実画面で確認しました。今回の接続で確認した結果であり、別の環境やURLの許可状態を示すものではありません。

通常CSVや設定JSONのネイティブファイル選択は、拡張機能のファイルアクセス権限が必要として停止しました。許可設定の変更や別経路での迂回は行っていません。利用者側の許可操作と、その後の再確認が残っています。デモの成功は通常ファイル選択の成功とは区別し、実ファイルへの出力も未確認です。
