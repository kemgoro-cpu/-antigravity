CSV Chart Viewer 操作マニュアル

初めて使う人から、日常の比較作業まで図・実画面・練習用データ付き
ファイルを開く→チャンネルを選ぶ→時間を合わせる→区間を比較・記録

このツールでできること

CSV / TRNの時系列を表示し、複数ログを比較します。選択区間の差・統計・状態の切り替わりを確認し、メモやレポートに残せます。

最初に覚える2つの言葉

チャンネルは車速・圧力などの1つの信号。基準ファイル（Main / M）は比較の起点、比較ファイル（Sub / s1…）は重ねる相手です。

読む順番：初めての操作 02〜05 ／ 比較と記録 06〜10 ／ 応用 11〜13 ／ 困ったとき 14。
対象：2026-09-29の比較ワークスペース。実画面はWindows / Microsoft Edgeで確認。表示幅・テーマ・読み込むファイルによって配置や数値が変わります。
02

まずは3つの操作で波形を見る

インストールやサーバーの起動は不要です。配布されたcsv_viewerフォルダー内のindex.htmlをブラウザで開きます。libなどの付属ファイルも一緒に置いてください。

  1. 「ファイルを選択」でログを開く

    CSV / TRNは画面へドラッグしても読み込めます。練習では、まず基準_ﾛｸﾞ.csv、続いて比較_ﾛｸﾞ.csvを追加します。

  2. 「チャンネルを選ぶ」からSpeedを選択する

    左の検索欄にSpeedと入力し、項目名をクリックします。2つのファイルの車速が同じ段に表示されます。

  3. 検索を消し、Pressureも選ぶ

    検索欄右の×で検索を解除し、Pressureを選択します。圧力の段が増えます。もう一度クリックすると、そのチャンネルを非表示にできます。

練習ファイルはこのマニュアルと同梱しています

基準_ﾛｸﾞ.csv ／ 比較_ﾛｸﾞ.csv
フォルダー：csv_viewer/docs/samples。個人の計測データを含まない合成ログです。

確認：SpeedとPressureが表示され、両方のログの線が見えれば準備完了です。

5 全体ナビゲーターログ全体のどこを見ているかを確認。開始／終了秒を入力して移動することもできます。

波形を広く見たい

上部の「ファイル」と「比較パネル」で左右を開閉します。境界をドラッグすると左パネルの幅を調整できます。

画面が小さいとき

比較パネルは波形の上に開きます。左パネルも引き出し式になります。×で閉じてから波形を操作します。

迷ったら上部の「操作マニュアル」へ別タブで開くため、今見ているログや選択状態を保ったまま参照できます。
04

ログを読み込み、信号を探す

読み込み前に形式を確認

標準は1行目がチャンネル名、2行目が単位、3行目以降が数値です。時間列の名前にはTimeまたは時間を使います。

Time,Speed,Pressure,State
s,km/h,kPa,
0,0,100,0
0.5,10,105,0
1,20,110,1

読み込み設定は左の「読み込み設定・計算・イベント」を開きます。見出しが違う行にあるときは、読み込み前に名前行・単位行を確認してください。

検索は名前以外でも使えます

PressureだけでなくkPaなどの単位でも絞れます。「検索別名」で「圧力」などを登録すると、その語でも探せます。

/ または Ctrl+Kで検索へ移動。↓で一覧に移り、Enter／Spaceで表示を切り替えます。

絞り込みが残っていませんか

「表示中」「全ファイル共通」「未対応あり」「お気に入りセット」で一覧を限定できます。「絞り込みを解除」で戻します。

単位行のないCSVは、そのまま読み込まないでください現在はTime行の直後を単位行として自動判定します。単位行を省くと最初のデータ行が単位として扱われることがあります。元ファイルを残し、コピーに単位行（不明な列は空欄）を追加してください。

文字化け：文字コードをShift_JISなどに指定して再読み込み。時間が1000倍違う：ファイルごとの「時間」をs / msから選択。単位の手動変更では操作履歴がリセットされます。

06

比較の準備と、3つの表示

  1. 比較パネルの「準備」で基準を確認する

    比較の起点にしたいファイルを「基準ファイル」で選びます。表示名は作業用の名前です。元ファイル名は変わりません。

  2. 同じ信号を対応付ける

    名前が同じ信号は通常そのまま比較できます。名前が異なる場合は、表示中のチャンネルの対応先を選び「対応を適用」。候補が表示されても、適用前は波形に反映されません。

  3. 目的に合わせて表示を切り替える

    「重ね合わせ」「上下比較」「差分」は上部で切り替えます。元のチャンネル配置は保持されます。

差分 = 基準ファイルの値 − 比較ファイルの値例：基準100 kPa、比較105 kPa → 差分は −5 kPa

「元の時刻で確認」とは

時間合わせによる表示上の移動を一時的に解除します。保存済みの時間差は消えません。時間合わせに依存するクロスファイル計算線は、この表示では非表示になります。

単位が違う場合

PaとkPaなどは自動換算しません。単位が一致しない組み合わせは、同じチャンネルの重ね合わせ・差分・数値比較から除外されます。

名前や単位が一致しても、同じ場所・同じ物理量を測った信号とは限りません。センサーと測定条件を確認してから対応付けてください。

07

時間を合わせる：プレビューして適用

  1. 「時間合わせ」で比較相手を選ぶ

    3ファイル以上なら、比較ファイルごとに行います。

  2. 特徴のある信号を選ぶ

    練習ではSpeedを選び、探索幅を±5秒にします。一定値の信号ではずれを特定できません。

  3. 「自動合わせをプレビュー」

    基準・現在・候補の3本と誤差を確認します。まだ保存済みの時間差は変わりません。

  4. 形が合っていれば「この時間差を適用」

    練習の比較ログは2秒後ろにずらしてあります。適用後の時間差は約−2秒です。

RMSEは、ずれの大きさを表す指標波形の値の誤差を二乗して平均し、平方根を取った値です。通常は小さい方がよく合っていますが、周期波形は別の周期へ合う場合があるため、特徴点も見てください。

手動で合わせる：「2点指定・数値で合わせる」を開き、同じ現象が起きた基準時刻と比較の元時刻を入力します。時間差は基準時刻 − 比較の元時刻。波形の2点をクリックして指定することもできます。

08

比較結果を読む

  1. 比較するチャンネルと区間を決める

    練習ではPressureを表示し、10〜30秒を選択します。時間合わせは−2秒を適用済みにします。

  2. 「区間比較」または「比較を更新」

    選択区間があればその区間、なければ現在の表示範囲を計算します。

  3. 値と条件を確認する

    圧力が比較側で5 kPa高いので、平均差は約−5 kPa。最大絶対差とRMS差は約5 kPaになります。

項目読み方
最大絶対差差の符号を外した最大値。常に0以上。
その時刻最大絶対差が発生した時刻。
平均差基準−比較の平均。方向が分かる。
RMS差正負が相殺されない差の大きさ。
有効／欠損・範囲外比較できた点数と、比較できなかった基準サンプル数。
許容差許容する差の絶対値。正の値を入力すると、超過した点数と最大差の倍率を表示。
描画を間引いていても、数値比較は元データから計算連続値は基準のサンプル時刻へ線形補間、Bit（0/1などの状態）は直前値を保持します。欠損をまたいだ補間や範囲外への外挿はしません。平均・RMSは有効サンプルの等重み平均です。

Bitの「同じ遷移の時刻差」は比較 − 基準で、値の差分と符号の向きが異なります。対象区間内の最初の切替が同じ遷移の場合に表示します。区間や条件を変えた後は「比較を更新」で再計算してください。

09

発見を残す・次のログに再利用する

比較メモを残す

  1. 区間を選び「メモ」を押す

    または比較パネルの「メモ・保存」を開きます。

  2. 事実と解釈を分けて書く

    例：「10〜30秒、Pressureの平均差−5 kPa。速度は時間合わせ後に一致。センサーのゼロ点差の可能性は要確認。」

  3. 「この区間をメモに保存」

    区間・チャンネル・ファイル・時間差・配置・式・対応・比較数値と波形画像が記録されます。

保存済みメモの区間リンクから、保存時の条件へ戻せます。保存時と同じ名前・数のログを開いておく必要があります。共有する場合は「メモ付きHTMLレポート」を保存します。

比較テンプレートを使う

テンプレート名を入力して「保存」。次のログを読み込んだ後、保存済みテンプレートを選び「新しいログに適用」を押します。

配置・選択・計算式・対応付け・許容差・検索別名・時間合わせ条件を再利用します。JSONで書き出して共有することもできます。

テンプレート適用後は時間合わせをやり直す前回の時間差は引き継がず0秒へ戻ります。対応は基準と比較ファイルの順番で移すため、どのログがs1・s2かも確認してください。ログデータやメモ画像はテンプレートに含まれません。

メモは20件まで。画像が保存上限を超える場合は画像なしで数値・条件を保存します（PNGのData URL文字列が400,000文字未満）。容量不足時は通知されます。入力中の下書きはパネル切替では残りますが、再読み込みをまたいでは保存しません。

11

計算・イベント・XYを使う

Custom RAM：計算チャンネル

左の「読み込み設定・計算・イベント」を開き、名前・単位・式を入力して「追加」。既存の信号から新しい信号を作ります。

Pressure * 1000
Speed / 3.6
Pressure - s1:Pressure

例の単位は順にPa、m/s、kPa。s1は比較ファイルの番号です。ファイルの順番を確認してください。式に使う信号名は読み込んだ名前に合わせます。

チャンネル横の「式に挿入」を使うと、入力欄を開いてその名前を挿入します。使える関数はCustom RAM横の「?」で確認します。

イベント検出：条件を満たす区間

条件式を入力して「検出」。基準ファイルで条件を評価し、最大300区間を一覧と波形のハイライトで表示します。行を押すとその区間へ移動します。

Pressure > 120
Speed > 30 && State == 1

繰り返し起きる状態を拾いたいときに使います。検出した区間は再起動で復元しないため、次回は再検出します。異常かどうかは測定条件と判定基準から判断してください。

区間選択との違い区間選択は自分で時刻を指定。イベント検出は条件に合う区間をログから探します。

XYプロット：時間以外の軸で関係を見る

「解析ツール → XYプロット」でXとYのチャンネルを選びます。例えばXをSpeed、YをPressureにすると、車速と圧力の関係を散布図として確認できます。同一ファイル内のX/Yペアを、各ファイルで重ね描きします。

12

波形の配置と、走行モードの評価

同じ段に重ねる・別の段に置く

左のチャンネル名をつかんで波形へドラッグします。同じ単位は軸を共有し、異なる単位は新しいY軸になります。細かい軸の割り当ては、重ねたチャートのY軸ラベルをダブルクリックして変更できます。

見やすくする操作場所
段の順番を変える解析ツール → 並べ替え。チャート枠を上下にドラッグ。
全体の高さ・文字・線を調整表示 → チャートの高さ／フォントサイズ／線の太さ。
1段だけ高さを調整段の下端境界をドラッグ。ダブルクリックで自動へ戻す。
Y軸範囲を固定左の選択チャンネルにあるmin / maxへ入力。差分表示はY軸自動。

Drive Index：走行モードの確認

「解析ツール → Drive Index」で車速・燃料流量などのチャンネルを指定し、モード・評価区間を確認して「再計算」を押すと、NEDC / WLTC / MDCなどの走行品質や燃費を確認できます。入力を変えた後も再計算が必要です。自動判別されたモード・MT/AT・評価区間が実際の試験と一致するか確認してください。

単位と評価範囲を先に確認車速はkm/h、燃料流量はL/hを前提に計算します。単位を検証して自動換算する機能はありません。Drive Indexは通常の波形ズーム・比較用の時間シフトとは独立です。既定のモードの目標トレースではモード区間を評価し、CSV列を目標にするとログの先頭〜末尾が全体評価の対象になります。後者では開始・終了指定と自動整合は使いません。

目標車速は@NEDC_MTなどのチャンネルとして追加されます。目標は既定でモードのトレースを使い、CSVの目標列を選択した場合はその列を使います。これはアプリによる解析支援です。正式な試験判定の代替とせず、使用する走行パターンと評価条件を別途確認してください。

Undoで戻せる操作・戻せない操作

ズーム、チャンネル選択、配置、計算チャンネル、色、比較設定、メモ削除などはUndoの対象です。ただしファイル追加・ファイル削除・全クリア・時間単位の手動変更では履歴をリセットします。履歴は再起動後に残りません。

削除の前に、保存先を確認する

「ファイルを外す」は比較と自動復元から外します。「作業をすべてクリア」はファイル・表示・比較メモ・履歴・復元情報をまとめて消します。元のCSV / TRNファイルはディスクから削除しません。確認画面でキャンセルできます。

症状確認すること・戻し方
ファイルを開いたのに波形がない左のチャンネルを選択。左パネルが閉じていたら「ファイル」またはCtrl+K。
欲しいチャンネルが見つからない検索文字を消し、「絞り込みを解除」。基準ファイルにそのチャンネルがあるか確認。
比較側の線だけ出ない準備でチャンネルの対応と単位を確認。「対応を適用」を押したかも確認。
先頭データが欠ける／単位に数値が出る単位行が省略されていないか確認。元ログを残し、コピーに単位行を追加して再読み込み。
文字が化ける読み込み設定の文字コードをShift_JIS等に指定し、該当ファイルを再読み込み。
時間が1000倍ずれるファイルの「時間」でs / msを確認。自動推定が合わない場合は手動指定。
自動時間合わせが候補を出さない変化がある信号、単位が一致する対応、十分重なる区間、適切な探索幅を選ぶ。周期が反復する信号では特徴点も確認。
別の場所を拡大したのに比較対象が変わらない色付きの選択区間が残っていれば、その区間が優先。区間操作バーの×で解除し再計算。
比較結果が消えた条件変更で古い結果を無効にしています。「比較を更新」で計算し直す。
メモを保存できない／画像がない波形・区間・本文を確認。上限20件、画像の保存上限、ブラウザ保存容量を確認。先にHTMLレポートへ書き出す。
差分表示から保存したCSVが差分でないCSV保存は基準側の元値。計算差分を作って表示し、そのチャンネルを出力。
画像コピーが失敗するブラウザ権限や起動方法に依存します。「PNG保存」で代用。
前回の作業が復元されない同じブラウザ・プロファイルか、保存容量やブラウザデータ消去の影響がないか確認。元ログと保存した設定JSONから再開。
パネルや文字が小さい左右パネルを閉じる、表示のフォントを「大」にする。線が重なる場合は上下比較へ切り替える。
問い合わせるときに残す情報操作の順番、起きた時刻、ファイル形式、文字コード、名前行／単位行、期待した結果を記録します。「読み込み情報」と画面画像があると再現しやすくなります。社外に渡すときは、測定データやファイル名を確認してください。
操作説明・画面例は同梱ソースと実際のブラウザ操作を照合しています。ツール更新後に表示名や手順が変わった場合は、マニュアルも更新してください。練習用CSVを使えば、元の計測ログを変更せずに操作を確認できます。
