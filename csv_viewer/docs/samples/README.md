# 練習用の合成データ

このフォルダーのCSVは操作確認用の架空データです。実車・実機エンジンの測定結果ではありません。

## 1つのファイルで燃費率マップを試す

`デモ_燃費率マップ付き走行ログ.csv` を通常の「開く」で読み込みます。

1. 別のログも開いている場合は、このデモを基準ログにします。
2. `Engine_Speed` と `Engine_Torque` を選んで波形を表示します。
3. 解析対象を「全体」にします。
4. 右上「XY・マップ」を開き、表示を「燃費率マップ」にします。
5. 「背景マップ・表示設定」で背景データを「基準ログのSFC列」にします。以前の設定が残っている場合、回転数格子幅400 rpm・トルク格子幅3 Nmに戻し、色の上下限を空欄にします。

波形で20～60秒を選択すると、その区間の401点だけがマップ上に表示されます。背景マップは全体のままです。波形上のカーソルにマップの菱形が追従し、マップの走行点をクリックすると波形の元時刻へ移動します。「等高線を重ねる」も試せます。

### デモの内容

- 時系列：0～120秒、0.1秒刻み、1,201点。回転数・トルク・冷却水温を滑らかに変化させています。
- 背景：800～6,000 rpmを400 rpm刻み、6～150 Nmを3 Nm刻みで定義した686座標。638座標に正の燃費率を入れ、残りは空白にしています。
- 中低回転・中高トルクで燃費率が低くなる架空の色分布です。特定のエンジン仕様や性能を表していません。
- 空白の見え方を確認するため、一部の内部セルと高トルク側を欠損にしています。背景用の定義が終わった後の `sfc_*` 列も空欄です。

背景欄の「除外563点」は、背景定義の空欄515行と無効セル48件の合計です。走行点1,201点の欠損を意味しません。

**`sfc_ne`・`sfc_te`・`sfc_g_kwh` は独立した背景マップの定義です。同じ行の走行回転数・トルクから燃費率を計算したものではありません。** 燃料流量からの燃費率算出機能を追加したわけではありません。

2026-11-01に、乱数を使わず三角関数と次の架空の分布式で生成しました。単位行はCSVビューアの読込形式に合わせたものです。

```text
回転数 = 2200 + 900 sin(t/9) + 400 sin(t/2.7)
トルク = 65 + 35 sin(t/11 + 0.6) + 12 sin(t/3.4)
冷却水温 = 75 + 15(1 - exp(-t/50))
背景燃費率 = 235 + 0.20((rpm-2600)/85)^2 + 0.40((Nm-90)/6)^2 + 160/(Nm/8+1)
```

背景は `Nm > 155 - 0.000004(rpm-2800)^2` の領域と、2,000～2,400 rpm／42～48 Nmの内部領域を空白にしています。

## その他の練習用CSV

- `基準_ﾛｸﾞ.csv` と `比較_ﾛｸﾞ.csv`：時間差2秒、圧力差5 kPaの比較練習。
- `練習用_エンジン.csv`：60秒の走行点表示の練習。
- `練習用_燃費率ﾏｯﾌﾟ.csv`：別CSVとして背景へ読み込む3列形式のマップ。

アプリ直下の `NEDC_sample_A.trn` にはトルク[Nm]がありません。このログを開いたままでも、外部CSVを適用して背景マップだけを表示できます。回転数とThrottle[%]から走行点を作ることはしません。走行点の重ね合わせ・時刻連動を試す場合は、上記のトルク入りデモまたは `練習用_エンジン.csv` を使ってください。
