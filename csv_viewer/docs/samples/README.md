# 練習用の合成データ

このフォルダーのCSVは操作確認用の架空データです。実車・実機エンジンの測定結果ではありません。

## 1つのファイルで燃費率マップを試す

`デモ_燃費率マップ付き走行ログ.csv` を通常の「開く」で読み込みます。

1. 別のログも開いている場合は、このデモを基準ログにします。
2. `Engine_Speed` と `Engine_Torque` を選んで波形を表示します。
3. 解析対象を「全体」にします。
4. 右上「XY・マップ」を開き、表示を「燃費率マップ」にします。
5. 「背景マップ・表示設定」で背景データを「基準ログのSFC列」にします。以前の設定が残っている場合、回転数格子幅400 rpm・トルク格子幅3 Nmに戻し、燃費率の上下限を空欄にします。

波形で20～60秒を選択すると、その区間の401点だけがマップ上に表示されます。背景マップは全体のままです。波形上のカーソルにマップの菱形が追従し、マップの走行点をクリックすると波形の元時刻へ移動します。背景の表示を「塗りつぶし／等高線のみ／両方」で切り替え、等高線の間隔を5・10・20 g/kWhなどに変更して比較できます。

### デモの内容

- 時系列：0～120秒、0.1秒刻み、1,201点。回転数・トルク・冷却水温を滑らかに変化させています。
- 背景：800～6,000 rpmを400 rpm刻み、6～150 Nmを3 Nm刻みで定義した686座標。638座標に正の燃費率を入れ、残りは空白にしています。
- 中低回転・中高トルクで燃費率が低くなる架空の色分布です。特定のエンジン仕様や性能を表していません。
- 空白の見え方を確認するため、一部の内部セルと高トルク側を欠損にしています。背景用の定義が終わった後の `sfc_*` 列も空欄です。

背景欄の「除外563点」は、背景定義の空欄515行と無効セル48件の合計です。走行点1,201点の欠損を意味しません。

**`sfc_ne`・`sfc_te`・`sfc_g_kwh` は独立した背景マップの定義です。同じ行の走行回転数・トルクから燃費率を計算したものではありません。** 燃料流量からの燃費率算出機能を追加したわけではありません。

2026-11-01に、乱数を使わず三角関数と次の架空の分布式で生成しました。単位行はCSVビューアの読込形式に合わせたものです。

```text
回転数 = 2200 + 900 sin(t/9) + 400 sin(t/2.7)
トルク = 65 + 35 sin(t/11 + 0.6) + 12 sin(t/3.4)
冷却水温 = 75 + 15(1 - exp(-t/50))
背景燃費率 = 235 + 0.20((rpm-2600)/85)^2 + 0.40((Nm-90)/6)^2 + 160/(Nm/8+1)
```

背景は `Nm > 155 - 0.000004(rpm-2800)^2` の領域と、2,000～2,400 rpm／42～48 Nmの内部領域を空白にしています。

## 詳細な等高線と欠損を試す

`練習用_詳細燃費率ﾏｯﾌﾟ.csv` は、細かい背景・等高線・数値ラベルの表示確認用です。**実測値でも、既存の粗いマップを補間した値でもありません。** 独立した架空の関数を各座標で計算しています。実機の燃費やトルク特性の評価には使用できません。

1. 右上「XY・マップ」を開き、表示を「燃費率マップ」にします。
2. 「背景マップ・表示設定」で背景データを「別のマップCSV」にします。
3. このCSVを選び、形式を「3列（X・Y・燃費率）」にします。単位確認にチェックを入れ、「背景に適用」を押します。通常の「開く」から読み込む走行ログではありません。
4. 燃費率の上下限を空欄に戻し、背景の表示を「等高線のみ」、等高線の間隔を10 g/kWhにします。5 g/kWhに変えると線が増えます。「両方」へ切り替えると元の格子の色面と照合できます。
5. 「拡大操作 OFF」を押してONにし、ホイール・ピンチで拡大、ドラッグで移動して主要線の数値と3,100 rpm／96 Nm付近の空白を確認します。「全体に戻す」で範囲が戻り、拡大操作もOFFになります。欠損をまたぐ等高線は作りません。

トルクのない `NEDC_sample_A.trn` を開いたままでも、背景だけを表示できます。走行点や時刻連動も試す場合は、トルク入りの `デモ_燃費率マップ付き走行ログ.csv` または `練習用_エンジン.csv` を基準ログにしてください。この詳細背景と走行点は別々の架空データであり、実測上の対応関係はありません。

### 詳細マップの定義と再生成

- 生成日：2026-11-01。乱数・外部データは使用していません。
- 回転数：800～6,000 rpm、100 rpm刻み、53座標。
- トルク：0～240 Nm、2 Nm刻み、121座標。
- 全6,413座標のうち、有効5,743座標、空白670座標（内部23、境界647）。CSVの空欄を0で埋めません。
- 有効値の範囲：232.125～457.253 g/kWh。小数第3位に丸めて保存しています。
- 既存の小さな `練習用_燃費率ﾏｯﾌﾟ.csv` と、マップ付き走行ログは変更していません。

各座標の値は次の架空の式です。中回転・中負荷の谷と、4,200 rpm／175 Nm付近の局所的な盛り上がりを持たせ、等高線の細かさを見比べられるようにしています。

```text
燃費率 = 220
       + 18 × ((rpm - 2400) / 1600)^2
       + 30 × ((Nm - 130) / 100)^2
       + 150 / (Nm / 12 + 1)
       + 22 × exp(-((rpm - 4200) / 650)^2 - ((Nm - 175) / 35)^2)
```

次の座標は空白にしています。これは欠損表示の練習用のマスクであり、実際のエンジンの運転限界を示すものではありません。

```text
境界：Nm < 6 または Nm > 240 - 0.000007 × (rpm - 3000)^2
内部：((rpm - 3100) / 180)^2 + ((Nm - 96) / 8)^2 <= 1
```

`csv_viewer` フォルダーで `node scripts/generate-detailed-fuel-map.js` を実行すると、同じCSVを再生成します。スクリプトはアプリと同じパーサーで格子数・有効数・空白・正値を確認してから、この詳細CSVだけを書き出します。

## その他の練習用CSV

- `基準_ﾛｸﾞ.csv` と `比較_ﾛｸﾞ.csv`：時間差2秒、圧力差5 kPaの比較練習。
- `練習用_エンジン.csv`：60秒の走行点表示の練習。
- `練習用_燃費率ﾏｯﾌﾟ.csv`：別CSVとして背景へ読み込む3列形式のマップ。

アプリ直下の `NEDC_sample_A.trn` にはトルク[Nm]がありません。このログを開いたままでも、外部CSVを適用して背景マップだけを表示できます。回転数とThrottle[%]から走行点を作ることはしません。走行点の重ね合わせ・時刻連動を試す場合は、上記のトルク入りデモまたは `練習用_エンジン.csv` を使ってください。
