# 設定読込専用の合成fixture

`manual-input-settings.json` は、2026-11-02に現行の設定スキーマ（version 7）を確認して**手作業で作成した入力検証用JSON**です。実アプリが書き出したファイルではありません。実測データ・計算結果・取得画像を含みません。メモの作成日時も検証用の固定値です。

このfixtureで確認できるのは、既存JSONを通常のUIから読み込む経路と、ファイル名による設定の適用です。**アプリからのダウンロード実体取得や、自分で書き出した設定の往復が成功した証拠には使えません。** メモの結果配列と画像は空にしてあり、架空の解析結果を表示しません。

## 前提と操作

1. 専用のHTTP開発プレビュー `?preview=1` で、同梱の[基準ログ](../../../samples/基準_ﾛｸﾞ.csv)と[比較ログ](../../../samples/比較_ﾛｸﾞ.csv)を通常の「開く」から読み込みます。
2. 「保存・再利用」→「今回の作業を再開」→「設定JSONを読み込む」で、このJSONを選びます。「次の試験へ比較条件」のテンプレート用読込には使用しません。
3. 適用完了後、以下の値を画面で確認します。通知だけで成功とは判定しません。
4. 比較パネルの「メモ」を開き、メモ本文・10〜20秒の範囲が残ることを確認します。範囲リンクの選択は任意です。
5. 同じJSONをもう一度読み込む場合は、同じ状態へ戻り、メモが重複して増えないことを確認します。

既存の選択チャンネル・比較設定・メモをこのfixtureの内容へ置き換えます。通常の作業タブでは使用しません。元のCSVファイルは変更しません。

| 項目 | 期待値 |

| 基準ログ | 元のファイル名 `基準_ﾛｸﾞ.csv`、Main、offset 0秒 |
