# Driving IndexのExcel方式

「Excel方式（通常指標）」は、提供されたExcelブックの通常指標6項目に合わせた計算です。「従来方式」も選択でき、再計算すると選択した方式を設定に保存します。方式や入力を変更した後は、再計算するまで以前の結果を現在値として表示しません。

## 入力と計算

時間は秒、目標・実測速度はkm/h、燃料流量はL/hです。目標速度は選択したモードのトレースを使います。Excel内の目標速度と比較する場合は、その速度列を目標車速欄で明示的に選んでください。対象区間、フェーズ、車両質量、走行抵抗A/B/Cも揃えます。

Excel方式では、通常のCSV/TRN信号は元ファイルから倍精度で読み直して計算します。表示用の波形バッファを置き換えません。計算チャンネルを入力にした場合、その計算済みデータの精度に従います。

全体と各フェーズをそれぞれ10Hzに線形補間し、次の処理を独立に行います。

1. 速度をm/sに換算し、中央5点移動平均を2回適用します。各回の両端2点はその回の値を保持します。
2. 約0.03m/s以下をゼロにします。負速度も計算上ゼロになります。閾値近傍は提供ブックの浮動小数点処理に合わせています。
3. 加速度は中央差分とし、区間の先頭・末尾はゼロにします。
4. 距離と仕事は区間右端の速度で積算します。走行抵抗も右端速度で評価し、正の駆動仕事を積算します。慣性質量係数は1.015です。
5. RMSSE、IWR、ASCR、DR、ER、EERを計算します。ER/EERには走行抵抗と質量が必要です。基準がゼロで比率を定義できない指標は未評価にします。

WOTや変速時の補正マスクは含みません。提供ブックの「通常指標」と比較してください。Excelファイルやマクロをブラウザで実行する機能ではありません。

## フェーズ

Excel方式のMDC初期値は、提供ブックの計算区切りをそのまま用いた0 / 589 / 1022 / 1477秒です。走行モード本来のMDC区切り0 / 451 / 1101 / 1477秒を使う場合は、フェーズ欄で変更できます。従来方式の初期値は従来のモード定義を使います。

全体結果は全区間を別に計算します。各フェーズ結果の平均ではありません。平滑化と端点処理は区間ごとに行うため、区間を分けた集計を単純に加えても全体と一致しない場合があります。

## 波形・燃費との関係

Excel方式の整形は6指標の計算専用です。チャート、TRNの負数、元サンプル、品質診断の値は変えません。燃料量・燃費・燃費用の距離は、元波形に対する従来の集計を維持します。Excel指標の内部で使う平滑化後の距離とは区別します。

不足・非有限値・不正な時間軸などにより評価できない場合は、理由を表示します。欠測をゼロに置き換えて正常な指標に見せることはしません。

## 確認範囲

提供MDCブックに残っていた中間入力から、全体と各フェーズの6指標を比較しています。提供WLTCブックには実測入力と現在結果がなかったため、同じVBA計算式に基づく合成入力で検証しています。WLTCの実測値との一致を確認したという意味ではありません。Excel原本や私的データはアプリに同梱しません。
