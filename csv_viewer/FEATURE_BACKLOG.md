## 第1弾(完了)

### F1: ライト/ダークテーマ切替
- **価値**: 印刷・資料貼り付け・明るい環境での閲覧。現状はダーク固定。
- **方針**: `styles.css` の `:root` トークンはそのまま(ダークが既定)、
  `:root[data-theme="light"]` でオーバーライド。チャート用の `T` は
  `cssVar()` 再解決関数(`refreshTheme()`)に変え、切替時に再計算 → `renderChart()`。
  `T.grid` / `T.axis` はCSSトークン化(`--chart-grid` / `--chart-axis`)して追従させる。
- **UI**: ツールバー右側にトグルボタン(bx-sun / bx-moon)。
- **永続化**: 設定キー `theme` を `collectSettings()` に追加し、`VISUAL_ONLY_KEYS` に登録。

### F2: カーソル計測(Δ計測)
- **価値**: 2点間の Δt・Δ値・区間統計を読み取る計測ビューアの定番機能。
  現状はツールチップの目視しかない。
- **方針**: ツールバーに計測モードボタン(ショートカット M)。モード中の
  チャートクリックで `convertFromPixel` により時刻を取得し、カーソルA→Bを設置。
  カーソル線は各グリッドの series markLine(`{ xAxis: t }`)で描く
  (ズーム・リサイズに自動追従)。3回目のクリックはAから置き直し。
- **統計**: 区間 [tA, tB] を `timeData` の二分探索で切り出し、表示中チャンネル
  ごとに Δ(端点差)・min・max・mean・RMS を計算してフローティングパネルに表示。
- **解除**: Esc またはモードボタン再クリックでカーソル・パネルを消す。

### F3: しきい値イベント検出
- **価値**: 「WHL_SPD > 120 の区間」等を自動検出し、ハイライト+ジャンプできる。
- **方針**: 式パーサ(app.js の `tokenizeExpr` / `parseExprToAST` / `evaluateAST`)に
  比較演算子(`> < >= <= == !=`)と論理演算子(`&& ||`)を追加。結果は 1/0 の
  Float32Array。優先順位: `|| < && < 比較 < 加減 < 乗除 < べき乗 < 単項`。
  Custom RAM の式でもそのまま使えるようになる(副次的価値)。
- **UI**: サイドバーに「Events」セクション。条件式入力 → 検出ボタン →
  連続 true 区間を一覧表示(開始・終了・継続時間)。行クリックで該当区間へ
  ズーム(dataZoom dispatchAction、**dataZoomIndex 必須**)。チャートには
  markArea で着色(`chart-options-utils.js` の `buildMarkArea` を流用)。
- **テスト**: パーサ拡張の単体テストを追加(比較・論理・優先順位・NaN扱い)。

### F4: セッション自動復元
- **価値**: オフラインアプリなのに毎回ファイルをD&Dし直す手間をゼロにする。
- **方針**: パース成功時に File(Blob)を IndexedDB(`csvViewerSession` DB)へ保存。
  起動時にストアを読み、あれば既存の `parseCSV` パイプラインへそのまま流す
  (ロール・オフセット・選択チャンネルは localStorage 設定の `fileInfos` 名前
  マッチで復元される既存機構をそのまま利用)。
- **掃除**: ファイル個別削除・Clear All 時に対応レコードを削除。
- **保護**: 合計サイズ上限(例 200MB)超過分は保存スキップ+トースト通知。
  IndexedDB が使えない環境(プライベートモード等)では黙って無効化。

## 第2弾(完了)

### F5: 表示範囲の統計サマリ
- ズーム中の可視範囲に追従して、表示チャンネルごとの min / max / mean / σ を
  一覧表示するパネル。dataZoom イベントは購読済みなので追従実装は容易。
  F2 の区間統計計算ロジックを「可視範囲」に適用する形で共通化できる。

### F6: 表示データのCSVエクスポート
- 表示中の時間範囲・選択チャンネル(**Custom RAM の計算結果を含む**)を
  CSV で書き出す。現状、計算結果をアプリ外へ持ち出す手段がない。
- 出力列: 時間 + 各チャンネル(ヘッダに単位)。サンプリングは生データ基準
  (LTTB 間引きは適用しない)。ダウンロードは PNG 保存と同じ a[download] 方式。

### F7: XYプロットモード
- 時系列ではなく任意チャンネル同士の散布図(例: 車速 vs 燃料流量)。
- モード切替 + X軸チャンネル選択UI。ECharts の scatter で実装。
  main/sub の重ね描きも同色規則(fileColors)で。

### F8: main/sub 差分カーブ
- 同名チャンネルの main−sub 差分を自動生成して重ね表示。時間軸は main 基準で
  sub を線形補間(タイムシフト `offset` 適用後)。タイムシフト機能と組み合わせて
  2試験の比較を定量化する。Custom RAM の crossref(`s1:Name`)評価器を流用可能。

### F9: レポート出力
- 全チャート+Drive Index 表を1枚の HTML / PNG レポートに整形して保存。
  `getChartImageDataURL()`(PNG生成)と Drive Index 計算は実装済みなので、
  テンプレートHTMLへの流し込みが主作業。

### F10: チャンネルセットのお気に入り
- よく見るチャンネルの組み合わせに名前を付けてワンクリック適用。
  設定プリセット(preset 基盤)の軽量版として、選択チャンネル+並び順のみを
  保存・適用する。プリセットの保存上限・検証ロジックを流用。
